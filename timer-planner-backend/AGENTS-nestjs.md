# Instrucciones del proyecto

- Trabaja únicamente dentro de este proyecto. No accedas ni hagas cambios fuera de su directorio.
- Usa `pnpm` para instalar dependencias y ejecutar scripts o herramientas del proyecto.
- No leas ni modifiques archivos salvo que el usuario lo solicite explícitamente. Limita la lectura a lo necesario para esa petición.
- Sigue las prácticas recomendadas oficiales y vigentes de cada herramienta que usemos. Para NestJS, consulta https://docs.nestjs.com/.
- Cuando el usuario pida un comando de NestJS, muestra el comando completo (`nest generate ...`) y su atajo (`nest g ...`) si existe.
- Responde de forma directa y breve, salvo que el usuario pida una explicación detallada.
- Si necesitas ejecutar un comando pide permiso y explica de manera breve que hara, por lo regular si es para lectura, escritura o modificaciones, explicalo claro

## Alcance del trabajo

1. **Solo dentro del proyecto.** Trabaja exclusivamente dentro de esta carpeta (`timer-planner-backend`) y de sus subcarpetas. No leas, busques, analices ni modifiques archivos fuera de este directorio.
2. **Solo bajo instrucción explícita.** No leas ni modifiques archivos dentro del proyecto a menos que el usuario te dé instrucciones para hacerlo.
3. **Entorno cerrado.** Todo el trabajo se realiza dentro de este entorno y de esta carpeta, sin excepciones.
