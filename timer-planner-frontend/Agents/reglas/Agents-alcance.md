# Reglas generales del frontend

Aplican a todos los agentes de `timer-planner-frontend`. Se suman a las reglas del monorepo, en `Agents/reglas/Agents-alcance.md`. Las rutas escritas como texto empiezan en la raíz del monorepo (`time-planner-app/`).

- Todo cambio de código, sea una fase de un plan o un arreglo suelto, sigue `timer-planner-frontend/Agents/funcionalidad/Agents-planner.md` (conflictos con las reglas y fases) y actualiza la documentación según «Qué documento tocar según el cambio» de `Agents/funcionalidad/Agents-documentacion.md`.
